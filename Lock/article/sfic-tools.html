3D-Printed Tools for SFIC Cores

Here are a few 3D models for tools to work on SFIC cores. Some are my own designs; others are models I found online.

Buying these tools from BEST can cost more than $800. Making them yourself is a much cheaper alternative!

Below are links to the four models:

  • Code Book A.stl
  • Code Book B.stl
  • Core.stl
  • Support Block.stl

Experiment, and have fun!

Only use these tools on locks you own or have permission to work on.
