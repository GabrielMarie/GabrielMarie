Make Your Own Key Decoder

I created Key-Decoder, a GitHub repository to help you build your own key decoder: an image overlay used to read a key's cut depths from a photograph.

Creating a decoder for a specific key type used to be a challenge. This project aims to make it easier than ever.

Explore the project, experiment, and have fun. For educational purposes only, and only with keys you own or have permission to analyze.
